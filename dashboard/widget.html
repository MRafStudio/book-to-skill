Про язык: имена API, фреймворков и точные названия сущностей остаются
    в оригинале даже в русском скилле — иначе их невозможно будет найти в документации.
    Переводится проза, определения и пояснения. description скилла всегда английский
    (Use when …) — по нему Hermes выбирает, когда скилл подгружать.

⚠ Показать предполагаемый скилл до записи?

      

      
Сам показ бесплатен — платится генерация: прочитать очищенный текст и записать
        скилл (SKILL.md, главы, глоссарий, паттерны, шпаргалка). После просмотра можно править
        и перегенерировать — каждая итерация оплачивается заново, поэтому счёт растёт кратно
        числу итераций, а не вдвое за один раз.

      
Установка в постоянные скиллы произойдёт только по отдельной команде.
